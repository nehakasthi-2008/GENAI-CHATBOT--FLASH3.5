# 🤖 GenAI Chatbot

A simple and interactive **Generative AI Chatbot** built using Python and Streamlit. The application provides a clean web-based interface that allows users to interact with an AI model and receive intelligent responses to their questions.

## 📌 About the Project

The **GenAI Chatbot** is a web-based conversational AI application developed to demonstrate the practical use of Generative AI.

The chatbot allows users to enter questions or prompts through an interactive interface and receive AI-generated responses. The application is developed using **Python** and **Streamlit**, making it lightweight, easy to use, and accessible through a web browser.

This project demonstrates how modern AI capabilities can be integrated into a simple application without requiring a complex user interface.

---

## 🎯 Objectives

The main objectives of this project are:

- To understand the fundamentals of Generative AI.
- To develop an interactive AI chatbot using Python.
- To create a user-friendly web interface using Streamlit.
- To understand how users interact with AI models through prompts.
- To deploy an AI application on the internet.
- To gain practical experience in developing and deploying AI-based applications.

---

## ✨ Features

- 🤖 **AI-Powered Conversations**  
  Users can interact with the chatbot using natural language.

- 💬 **Interactive Chat Interface**  
  Provides a simple interface for entering questions and viewing responses.

- ⚡ **Real-Time Responses**  
  AI-generated responses are displayed directly in the application.

- 🌐 **Web-Based Application**  
  The chatbot can be accessed through a web browser.

- 🎨 **Simple User Interface**  
  Streamlit provides a clean and easy-to-use interface.

- ☁️ **Online Deployment**  
  The application is deployed using Streamlit Community Cloud.
